# Lista de Tarefas em Python
Aplicacao simples de gerenciamento de tarefas desenvolvida em Python como projeto academico.
## Funcionalidades
- Adicionar novas tarefas
- Listar tarefas existentes
- Marcar tarefas como concluidas
- Remover tarefas
## Tecnologias
- Python 3.x
## Como executar
```bash
# Clone o repositorio
git clone https://github.com/danrevoltz/lista-de-tarefas-python.git
# Entre na pasta
cd lista-de-tarefas-python
# Execute o programa
python main.py
```
